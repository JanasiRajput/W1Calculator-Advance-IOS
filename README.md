# W1Calculator

A simple calculator application built with **SwiftUI** as part of my iOS development coursework.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear/reset functionality
* Basic error handling for division by zero
* Custom reusable button styling

## Tech Stack

* Swift
* SwiftUI
* Xcode

## What I Practiced

This project helped me practice:

* SwiftUI views and layouts
* `@State` for managing UI state
* Button actions
* Functions and reusable components
* Basic arithmetic operations
* Custom `ButtonStyle`
* Conditional logic
* Git and GitHub workflow
